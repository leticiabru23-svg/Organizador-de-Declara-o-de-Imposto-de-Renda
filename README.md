# 📊 Organizador de Declaração de Imposto de Renda (IRPF)

Ferramenta desenvolvida em **Microsoft Excel** para auxiliar na organização e no controle das informações financeiras necessárias para a preparação da **Declaração de Imposto de Renda da Pessoa Física (IRPF)**.

O projeto tem como objetivo centralizar os dados do contribuinte, facilitando o registro, a consulta e a conferência das informações financeiras ao longo do ano.

## 📌 Funcionalidades

- 📊 **Titular:** Cadastro e organização dos dados do contribuinte.
- 💼 **Informes:** Registro detalhado das informações por instituição bancária, incluindo valores atuais e anexos.
- 🏠 **Notas:** Controle mensal das receitas, com registro de datas, categorias e valores de entrada.

## 🗂️ Estrutura do Arquivo

O arquivo foi organizado em três abas principais:

| Aba | Descrição |
|---|---|
| **Titular** | Informações cadastrais e dados do contribuinte. |
| **Informes** | Dados financeiros organizados por banco, valores e anexos. |
| **Notas** | Registro mensal de receitas, datas, categorias e valores. |

## 🎯 Objetivo

Facilitar a organização das informações financeiras e proporcionar uma visão mais clara e estruturada dos dados utilizados na preparação da declaração do IRPF.

## 🛠️ Tecnologias

- Microsoft Excel
- Validação de dados
- Fórmulas e funções
- Organização e estruturação de dados
- Arquivo `.xlsm`

> ⚠️ **Observação:** Este projeto possui finalidade educacional e organizacional. As informações devem ser conferidas antes de serem utilizadas em uma declaração oficial.
